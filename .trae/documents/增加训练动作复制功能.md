## 需求理解
- 在“力训标签”里，对二级标签（器械/动作）提供“复制动作”能力。
- 复制后自动生成一个新动作：名称=原动作名称+“副本”（并处理重名），并保留原动作的分类。
- 同时把该动作下的三级标签（重量列表）一并复制到新动作下。

## 代码定位
- 动作/重量统一使用 Core Data 实体 TrainingTag（level=1 门店，level=2 动作，level=3 重量）。
- 最自然的入口在标签管理的动作列表：TrainingTagListView 的 currentLevel==2 分支里每行已有“编辑/删除”的菜单与右滑操作。
  - [TrainingTagListView.swift](file:///Users/imac/Documents/Projects/MuscleMetric/MuscleMetric/Views/TagManagement/TrainingTagListView.swift)

## 实现方案
1) 增加可复用的复制函数（建议放在 TrainingTagListView 内的 private func 或单独 extension）
- 入参：sourceAction: TrainingTag（要求 level==2）、viewContext。
- 生成新动作：
  - parent 复用 sourceAction.parent（同门店）
  - level=2，category 复用
  - name 生成规则：
    - baseName = (source.name ?? "") + "副本"
    - 若同门店下已存在同名动作，则依次尝试 baseName+"2"、"3"… 直到不冲突
- 复制重量：遍历 sourceAction.children（按名称排序），对每个 child（level3）创建新 TrainingTag：
  - level=3，name 复用，parent 指向新动作
- 最后 try viewContext.save()。

2) 在动作行增加“复制”入口
- 在 currentLevel==2 的动作行：
  - contextMenu 增加 Button("复制")
  - swipeActions 增加一个“复制”按钮（例如 icon=doc.on.doc，tint 可用灰/绿）
- 触发后调用复制函数；复制完成后无需跳转，列表会自动刷新。

3)（可选增强）复制后快速定位
- 复制成功后自动导航到新动作的重量列表页，或弹一个轻量提示（例如 Alert/Toast）。
- 这步我会先按“复制即生效、列表可见”为默认实现，若你更想自动跳转，我再补上。

## 验证方式
- 在模拟器/真机：进入“标签管理 → 力训标签 → 选择某门店 → 器械/动作（二级）”。
- 对任一动作执行“复制”，检查：
  - 新动作名称按规则出现（含重名递增）。
  - 分类与原动作一致。
  - 进入新动作，三级重量与原动作一致。
  - 保存后重新启动 App 数据仍存在。
